\section{Error and Error Rate}

\subsection{Error}

The {\bf error} $\ve{e}(t)$ between two signals 
$\va(t)$ and $\vb(t)$ is 
defined as the difference between the two signals, 
\be
\ve{e}(t) \defe \abs{\va(t) - \vb(t)}.
\ee
Note that $\ve{e} \geq \ve{0} \;\; \forall \;\; t$.
If $\vb$ exactly follows $\va$ at every time step, then the
error is zero, as expected.  

\begin{Hexample}
{
Let vectors $\va$ and $\vb$ be defined as follows,
\begin{align}
 \va & = {\tt [\; 20, 20, 20, 20 \;]} \\
 \vb & = {\tt [\; 18, 18, 18, 18 \;]}
\end{align}
Then the error $\ve{e}$ is found to be,
\be
 \ve{e} = {\tt [\; 2, 2, 2, 2 \;]}
\ee
In this example, assuming $\va$ is the ground truth, $\vb$ 
underestimates $\va$ by $2$ at every sample.  This is an 
example of {\bf systemic error}, where there is a consistent
offset between the two signals, and an offset adjustment (the
offset value of $2$ in this case) would eliminate all error 
between the two signals.
}
\end{Hexample}

\subsection{Accumulated Error}

Next, we would like to have a scalar value to describe the 
error over the entire sample, which is measured at each sample
point and has dimension $n$. 

We define the {\bf L1-norm accumulated error}, 
$\parallel \ve{e} \parallel_1$, as the sum of the errors
of each of the measurement,
\be
\parallel \ve{e} \parallel_1 \; \defe 
\sum_{i=0}^{n-1} \abs{e_i} = 
\sum_{i=0}^{n-1} \abs{a_i - b_i}.
\ee
This is the L1-norm, applied to each error measurement, $e_i = a_i - b_i$.  
A serious problem with accumulated error is that the error 
increases the more times the signals are measured. 

\begin{Hexample}
{
\begin{itemize}
\item In the preceding example, 
if the signals were measured at only 
one sample, the accumulated error would be $2$.  
\item Similarly, 
if two samples were taken, the accumulated error would be $4$.
\item For three samples, the accumulated error would be $6$.  
\item For 
the example as stated above, with four samples, the accumulated
error is $8$.  
\end{itemize}
This pattern shows the limitation of accumulated error: that
it is dependent on sample size.
}
\end{Hexample}
We define the {\bf L2-norm accumulated error}, 
$\parallel \ve{e} \parallel_2$, as the sum of the errors
of each of the measurement,
\be
\parallel \ve{e} \parallel_2 \; \defe 
\left( 
    \sum_{i=0}^{n-1} \abs{e_i}^2
\right)^{\half} = 
\left( 
    \sum_{i=0}^{n-1} \abs{a_i - b_i}^2
\right)^{\half}.
\ee
This is the L2-norm, applied to the error 
measurement, $e_i = a_i - b_i$.  
The systemic error seen above for 
the L1-norm, that the error increases with
increasing number of measurements,  also occurs for the L2-norm.
To remedy this effect, 
normalization by the sample count, called
{\bf error rate}, will be used.

\subsection{Error Rate}
\label{sec:error_rate}
The concept of {\bf error rate} is to 
normalize the accumulated 
error for any L$p$-norm type
by the 
dimension $n = \mbox{len}(\va) = \mbox{len}(\vb)$ of the signals. 
The resulting metric then reports error 
on a {\em per-measurement basis}, 
which eliminates the accumulation of error.  Specifically, the 
{\bf L1-norm error rate} is defined as 
\be
\parallel \bar{\ve{e}} \parallel_1 \; \defe 
\frac{1}{n} \; \sum_{i=0}^{n-1} \abs{e_i} = 
\frac{1}{n} \; \sum_{i=0}^{n-1} \abs{a_i - b_i},
\ee
and the {\bf L2-norm error rate} is defined as  
\be
\parallel \bar{\ve{e}} \parallel_2 \; \defe 
\frac{1}{n} \; \left( 
    \sum_{i=0}^{n-1} \abs{e_i}^2
\right)^{\half} = 
\frac{1}{n} \; \left( 
    \sum_{i=0}^{n-1} \abs{a_i - b_i}^2
\right)^{\half}.
\ee
Notice that the error rate units are [amplitude/sample], 
hence the rate of the errors in the amplitudes.

\begin{Hexample}
{
Revising the example with vectors $\va$ and $\vb$,
\begin{align}
 \va & = [\; 20, 20, 20, 20 \;] \\
 \vb & = [\; 18, 18, 18, 18 \;] 
\end{align}
The {\bf L1-norm error rate} $\parallel\bar{\ve{e}}\parallel_1$ 
is found to be,
\be
 \parallel\bar{\ve{e}}\parallel_1 
 \; = \frac{1}{4} \cdot \left(2 + 2 + 2 + 2\right) = 2.
\ee
The {\bf L2-norm error rate} $\parallel\bar{\ve{e}}\parallel_2$ 
is found to be,
\be
 \parallel\bar{\ve{e}}\parallel_2 
 \; = \frac{1}{4} \cdot \sqrt{\left(4 + 4 + 4 + 4\right)} = 1.
\ee
}
\end{Hexample}
