## Equations

When $a \ne 0$, there are two solutions, $x_1$ and $x_2$, to $f(x) = ax^2 + bx + c \overset{{\rm set}}= 0$ which are
$$ x_{1,2} = {-b \pm \sqrt{b^2-4ac} \over 2a} $$
