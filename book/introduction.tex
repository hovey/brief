\chapter{Introduction}
\section{Purpose and Scope}

\begin{itemize}

\item The purpose of this manuscript is to memorialize the
theories of solid dynamics used for the implementation
of a finite element code in Python.

\item The scope is simply to include a listing of variables,
equations, and methods used.  It is not intented to
be a substitute for textbooks on continuum mechanics and
the finite element method.

\item This manuscript was written by Dorival Piedade Neto and 
Chad Brian Hovey.

\end{itemize}
