# sandia-letter LaTeX class

If you are using LaTeX to write a letter from Sandia National Laboratories, then
this page might be of interest to you. The class file will help you format your letter according to
the official corporate look-and-feel guidelines published by Creative Services. 
The class file produces the necessary OUO markings if needed.

*Please note*: this class file is neither official or corporate-supported, and is maintained on a
best-effort and volunteer basis. 

## Download and Contribute
Clone the git repository

## Contact

Suggestions, bug fixes, and contributions are welcome and encouraged! We're not TeX/LaTeX experts,
so please feel free to make suggestions when you see things that have been done wrong or
awkwardly. Also consider joining the gitlab sandia-letter latex project in order to create branches in the
repo with your changes and improvements which can then be merged back into the master branch.
